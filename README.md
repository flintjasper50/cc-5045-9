# scenepin — 场景固定与求值一致性

把模型、纹理、字体、动画时刻与插件参数整理为不可变任务清单（按内容寻址），
由多台模拟渲染工作站按清单取确切内容并完成确定性出图，并对“不同工作环境是否
产出同一画面”给出可对账的证据。

## 图形入口（主入口）

```bash
python3 start.py                 # 启动出图任务面板 http://127.0.0.1:8471
python3 start.py --reset         # 清空 store/nodes/scenes 后重新初始化
```

面板能力：

- **场景来源 → 固定并提交**：解析依赖闭包、拒绝违规引用，生成修订与场景指纹。
- **场景修订列表**：显示场景指纹、动画时刻、插件参数、跨节点一致性徽标。
- **回归样例**：左侧“回归样例”列出已固定修订；点击即可打开，或在“版本摘要”里
  用下拉框切换样例后点“出图并核对画面”，将实际像素与版本摘要对照。
- **版本摘要**：清单哈希、场景指纹、分辨率、动画时刻、插件参数、资源摘要。
- **跨节点一致性**：两张节点结果并列展示场景指纹与像素 sha256，并给出逐像素渲染
  差值（不同像素数、比例、最大通道差）。
- **异常提示**：固定失败（含引用来源链）与节点失败、跨节点不一致均以顶部横幅提示，
  且来自实际出图结果，不以默认值掩盖。

## 命令行（辅助入口）

命令行仅作自动化与排障辅助，图形面板才是场景固定的主入口。

```bash
python3 tools/verify.py                        # 原有固定/一致性回归
python3 tools/acceptance.py                    # 求值一致性自动验收
python3 tools/acceptance.py --evidence out.json  # 落盘执行证据
python3 -m unittest discover -s tests -t tests # 一致性测试
```

`tools/acceptance.py` 会运行 `tests/` 全部一致性测试，并现场固定一次演示场景，
用独立参照实现核对场景指纹与渲染差值，输出可按修订对账的执行证据（JSON）。

## 一致性核验要点

- **场景指纹**（`scenepin/fingerprint.py`）：对依赖资源摘要、规范化设置（含动画时刻
  与插件参数）和入口路径取内容摘要。不依赖版本字符串、固定时间或工作站路径，因此
  任何工作站都应得到相同指纹。
- **真实像素**（`scenepin/compare.py`）：解码 PNG 求像素摘要，并逐像素计算渲染差值；
  比较的是像素而不是 PNG 文件哈希或版本字符串。
- **受控错误注入**（`scenepin/faults.py`，仅测试使用）：`swap-asset`、`default-config`、
  `zero-time`、`no-verify`、`omit-asset-digest`。测试会用它们构造正反例，断言场景指纹
  与渲染差值确实能暴露坏结果。未设置 `SCENEPIN_FAULT` 时行为完全正常。
- **独立参照**（`tests/reference.py`）：独立解码 PNG、独立规范化设置、独立计算指纹与差值。
  期望值从规格独立推导，不复用被测实现。

## 场景格式补充

场景 JSON 在原有字段外新增：

- `animation`: `{"time_ms": 0, "fps": 24}` — 冻结的动画时刻；模型 `spin`（每秒绕 Y 轴角度）
  随该时刻旋转。
- `plugins`: `exposure.gain`、`vignette.strength`、`tint.color/amount` — 缺省即按内置默认值，
  解析后的值会写入清单与指纹。未知插件、未知参数或越界值在固定期被拒绝。

## 一致性测试与工作站一致性

`tests/test_consistency.py` 覆盖：

- 场景指纹与独立参照一致、跨工作站一致、同名换件必变、动画/插件必变；
- 渲染差值与独立参照一致，同清单两节点逐像素零差；
- 动画时刻与插件参数确实改变真实像素；
- 五类受控错误的正面/反面对照，证明测试能拒绝不一致环境；
- 跨节点比较在证据缺失时报错而不是当作一致；
- 保持既有固定/出图语义（同内容复用修订、源文件改动不影响已固定修订）。

测试与实现一同入库；运行时状态（`store/`、`nodes/`、`.verify/`）按 `.gitignore` 忽略。
